💾 Données

Sauvegarde locale

Dans cette version, les données sont enregistrées dans le navigateur utilisé. Elles ne se transfèrent pas automatiquement vers un autre téléphone ou ordinateur.

Exporter budget et objectifs
Le bouton télécharge un fichier JSON contenant les revenus, les enveloppes du budget et les objectifs enregistrés dans cette partie. Garde ce fichier dans un endroit facile à retrouver.
À propos de Réinitialiser
Après confirmation, le budget et les objectifs personnalisés de cette partie sont retirés de ce navigateur, puis la page se recharge. Le projet de démonstration « Voyage en Crète » peut réapparaître. Ce bouton ne supprime pas les dépenses réelles du registre.
Les autres données de l’application (comme les opérations réelles et certaines charges) sont gérées dans d’autres parties et par leur propre sauvegarde. Il n’y a pas encore de synchronisation automatique entre appareils.
📱 Mobile

Expérience téléphone

La mise en page s’adapte à la largeur de l’écran pour rendre les cartes et les formulaires plus faciles à lire sur téléphone.

Sur un petit écran
Les grands tableaux de bord passent en une colonne, les champs des formulaires s’empilent et les boutons se réorganisent pour rester accessibles.
Sur tablette et ordinateur
Les cartes peuvent s’afficher côte à côte pour profiter de l’espace disponible.
À savoir
Cette adaptation concerne l’affichage. Elle ne synchronise pas les données du téléphone avec celles de l’ordinateur. L’affichage doit encore être vérifié sur les appareils utilisés.
